# EV car (g_057) Blender icon

**Approved 2026-09-30** (owner: "approved.", on v6). The internal name is `ev_car`. v6 is installed as the approved
alternate, `assets/icons/goods/alternate_icons/{medium,small,very_small}/g_057_ev_car.png` (800, 450 and 256 px), and
listed in `approved_manifest.json` with source `goods_ev_car/v6`. The shipped main art is unchanged; the alternate
takes priority at runtime.

**Provenance:** the car is built from a model the owner downloaded (`asfcsadfvasew.blend`, a TOGG T10X-like SUV), heavily
modified. Its source and licence were not recorded. Check them before any public release.
