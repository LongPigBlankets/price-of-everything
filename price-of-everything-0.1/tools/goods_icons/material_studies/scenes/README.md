# Approved editable scenes

These five scenes capture the approved versions. Coal and iron ore are installed as
runtime defaults; limestone, ethylene and electrical components are in alternate_icons.

The neighbouring builders reproduce the geometry and render passes. The PNG exporter
adds outer contours, overlap separation and shadow halftone. Direct Blender renders
therefore differ from the finished game PNGs. This folder is excluded from Godot import;
the game loads the PNG tiers under assets/icons/goods.
