Handoff library for junior/mid-level engineers and small AI models. Authored 2026-07-05
by the outgoing principal session; every command and constant verified against the repo
that day. Each skill's frontmatter `description` says exactly when to load it; each ends
with re-verification commands for anything that drifts.
